# line-following-agv
An autonomous line-following AGV designed to navigate along a predefined path using sensors and motor control.

## Project Overview

This project demonstrates the design and development of an autonomous mobile robot capable of detecting and following a marked path without manual control.

The AGV uses IR sensors to detect the line and a microcontroller to process sensor inputs and control the motors accordingly.

## Key Features

- Autonomous line tracking
- IR sensor-based line detection
- Differential motor control
- Real-time sensor feedback
- Microcontroller-based control system

## Hardware Components

- Microcontroller
- IR sensor array
- DC geared motors
- Motor driver
- Robot chassis
- Wheels
- Battery / Power supply
- Connecting wires

## Software

- C/C++
- Arduino IDE
- Embedded programming

## Working Principle

The IR sensors continuously detect the position of the line.

Based on the sensor readings, the microcontroller determines whether the AGV needs to move forward, turn left, or turn right.

The corresponding control signals are then sent to the motor driver to control the motors.
